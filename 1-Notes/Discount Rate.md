# Discount Rate

- **In plain words:** the return you give up by waiting — what you could earn elsewhere for similar risk.
- **Why it matters:** raising the rate lowers present value, and the effect grows with time, so long-dated cash flows are very sensitive to it.
- **Riskier cash flows get higher rates,** because investors demand more return for more uncertainty.
